05 / Quality & Standards

Engineering estimate — not a certified ASTM D1250 calculation.

This site uses an editable, constant thermal-expansion coefficient. It does not reproduce the full API MPMS Chapter 11.1 / ASTM D1250 density-dependent algorithms, pressure corrections, hydrometer corrections, or validated rounding rules. Do not use its results for custody transfer, official laboratory certification or contractual reporting without independent validation.

For reference, Energy1 describes its calculator as ASTM D1250-04 / API MPMS 11.1 Table 53B for refined products. This independent tool does not claim numerical equivalence.
